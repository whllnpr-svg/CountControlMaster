## 📦 对象池优化架构（建议）

```
┌────────────────────────────────────────────────────────┐
│              对象池优化架构 (推荐实现)                    │
└────────────────────────────────────────────────────────┘

当前架构（未优化）：
    Instantiate() ─────▶ [新对象]
    Destroy() ─────────▶ [销毁]
    性能问题：频繁GC，内存碎片

优化后架构：

┌──────────────────────────────────────────────┐
│             ObjectPoolManager                 │
│              (全局单例)                        │
├──────────────────────────────────────────────┤
│                                                │
│  Dictionary<GameObject, ObjectPool> pools      │
│                                                │
│  GetPool(prefab) → ObjectPool                 │
│  CreatePool(prefab, size)                     │
│                                                │
└────────────┬──────────────┬───────────────────┘
             │              │
    ┌────────┘              └────────┐
    │                                │
    ▼                                ▼
┌─────────────────┐         ┌─────────────────┐
│ StickmanPool    │         │ ParticlePool    │
│ (火柴人对象池)   │         │ (粒子对象池)     │
├─────────────────┤         ├─────────────────┤
│                 │         │                 │
│ Queue<>         │         │ Queue<>         │
│ ├─ [obj1]       │         │ ├─ [particle1]  │
│ ├─ [obj2]       │         │ ├─ [particle2]  │
│ ├─ [obj3]       │         │ └─ [particle3]  │
│ └─ ...          │         │                 │
│                 │         │                 │
│ Get()           │         │ Get()           │
│ Return()        │         │ Return()        │
│                 │         │                 │
└─────────────────┘         └─────────────────┘
        │                            │
        │                            │
        ▼                            ▼
┌─────────────────┐         ┌─────────────────┐
│ PlayerManager   │         │stickManManager  │
├─────────────────┤         ├─────────────────┤
│                 │         │                 │
│ 获取单位：       │         │ 血液效果：       │
│ pool.Get()      │         │ pool.Get()      │
│ ↓               │         │ ↓               │
│ 使用对象        │         │ 显示粒子        │
│ ↓               │         │ ↓               │
│ pool.Return()   │         │ pool.Return()   │
│                 │         │                 │
└─────────────────┘         └─────────────────┘

性能提升：
✓ 减少GC压力
✓ 提高实例化速度
✓ 降低内存碎片
✓ 支持更多单位数量
```

## 🔀 数据流向图

```
┌────────────────────────────────────────────────────────┐
│                    数据流向分析                          │
└────────────────────────────────────────────────────────┘

用户输入
   │
   ▼
[Input.mousePosition]
   │
   ▼
PlayerManager.mousePosition
   │
   ▼
计算目标X = Mathf.Clamp((mousePosition.x / Screen.width) * range)
   │
   ▼
player.position.x = Lerp(current.x, target.x, smoothSpeed)
   │
   ▼
Cinemachine 自动跟随
   │
   ▼
屏幕显示更新

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

碰撞检测
   │
   ▼
OnTriggerEnter(Gate)
   │
   ├─ GateManager.multiply (bool)
   ├─ GateManager.randomNumber (int)
   │
   ▼
计算新人数
   │ if multiply:
   │    numberOfStickmans *= randomNumber
   │ else:
   │    numberOfStickmans += randomNumber
   │
   ▼
循环实例化新单位
   │
   ▼
FormatStickMan() 计算位置
   │
   ▼
DOTween 动画播放
   │
   ▼
UI 更新 CounterTxt.text = numberOfStickmans.ToString()

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

战斗触发
   │
   ▼
OnTriggerEnter(Enemy)
   │
   ├─ attack = true
   ├─ playerSpeed → attackMoveSpeed
   │
   ▼
StartCoroutine(EnemyAttack(enemy))
   │
   │ [循环]
   ├─ numberOfStickmans--
   ├─ numberOfEnemyStickmans--
   ├─ CounterTxt.text 更新
   ├─ yield return null
   │
   ▼
判断结果
   │
   ├─ if player > 0: 继续游戏
   └─ if player <= 0: GameOver

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

到达终点
   │
   ▼
OnTriggerEnter(Finish)
   │
   ├─ gameState = false
   ├─ moveByTouch = false
   ├─ SecondCam.SetActive(true)
   │
   ▼
Tower.BuildTower()
   │
   ├─ 计算总层数
   ├─ 循环每一层
   │  ├─ 计算该层人数
   │  ├─ 计算每个位置
   │  ├─ DOLocalMoveY(yPos)
   │  └─ yield WaitForSeconds(0.2)
   │
   ▼
显示胜利UI
```
